# AGENTS.md

## 프로젝트 개요
- 자연어 기반 AI 식단 기록 서비스
- 사용자의 입력 편의성을 중요하게 고려한다.

## 기술 스택
- Backend: Java 21, Spring Boot, MyBatis
- Frontend: React 19, Vite, Tailwind CSS
- Database: MySQL
- Infra: Docker, Nginx, GitHub Actions
- AI: OpenAI Responses API

## 백엔드 개발 규칙
- Controller, Service, Mapper의 책임을 분리한다.
- 기존 프로젝트의 코드 작성 패턴을 유지한다.
- 사용자 소유 데이터 접근 시 user_id를 검증한다.
- 예외 발생 시 적절한 HTTP 상태 코드를 반환한다.

## 보안 규칙
- 기존 JWT 인증 및 갱신 구조를 임의로 변경하지 않는다.
- API Key, 비밀번호 등 민감한 정보를 노출하지 않는다.
- 인증 및 인가 관련 변경은 별도로 검토한다.

## AI 작업 방식
- 코드 수정 전 문제의 원인과 해결 방향을 설명한다.
- 요청 범위를 벗어난 코드는 수정하지 않는다.
- 여러 해결 방법이 있다면 장단점을 설명한다.
- 사용자 승인 없이 커밋하거나 배포하지 않는다.

## 학습 지원
- 사용자가 직접 구현하며 학습하는 것을 우선한다.
- 코드 분석 요청 시 임의로 코드를 수정하지 않는다.
- 수정이 필요한 이유와 관련 개념을 설명한다.

## 검증
- 코드 변경 후 관련 빌드 및 테스트를 수행한다.
- 테스트하지 못한 항목은 명시한다.
- 변경된 파일과 변경 이유를 정리한다.
